# Altacod — обзор проекта

Цель: многостраничный адаптивный сайт для привлечения малого бизнеса к услугам автоматизации нестандартных процессов вокруг 1С.

Позиционирование: 1С остаётся ядром учёта; Altacod связывает её с другими системами, устраняет ручной перенос данных и помогает раньше замечать финансовые риски. `Altacod Radar` — концепция системы раннего предупреждения, а не заявленный готовый коробочный продукт. ИИ применяется только там, где обычных правил недостаточно; финансовые расчёты выполняются детерминированно.

Первая целевая аудитория: оптовая торговля, небольшое производство, сервисные компании и селлеры маркетплейсов с существующими 1С, Excel и внешними системами.

Первичный источник требований: [ТЗ](../../ТЗ%20для%20Codex%20%E2%80%94%20сайт%20Altacod_%20автоматизация%20малого%20бизнеса%20вокруг%201С.md). Первый этап и порядок реализации описаны в [FIRST_STAGE_PLAN.md](FIRST_STAGE_PLAN.md).
