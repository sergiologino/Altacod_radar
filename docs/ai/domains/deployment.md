# Публикация доменов

- Coolify расположен на домашнем сервере без белого IP. Существующий каталог Altacod работает как отдельное приложение; новый корпоративный сайт должен стать новым отдельным приложением.
- Публичный сервер Timeweb: `89.223.66.64`, SSH-пользователь `root`. Caddy работает из `/etc/caddy/Caddyfile`; HTTP 80 принимает напрямую. nginx на внешнем 443 передаёт TLS по SNI на Caddy `127.0.0.1:8443` для доменов Altacod. Caddy направляет запросы к домашнему серверу `192.168.0.101` с внутренним Host для Coolify.
- Сейчас `altacod.com` направлен на `altacod-apps.sslip.io`; `www.altacod.com` перенаправляется на apex. Маршрут `products.altacod.com` ещё отсутствует.
- Цель миграции: действующий каталог — `products.altacod.com`, новый корпоративный сайт — `altacod.com`, `www.altacod.com` — постоянный редирект на apex, старые адреса `/apps/{slug}` — на каталог.
- Изменения других доменов и приложений не входят в миграцию. Перед правкой Caddyfile нужна копия текущего файла, проверка синтаксиса, затем проверки маршрутов и план отката.
