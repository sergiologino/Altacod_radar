# Правила проекта

- Язык пользовательского интерфейса — русский. Тексты конкретны и описывают процессы клиента, без образа универсальной IT-студии.
- В пользовательских текстах писать «ИИ». Избегать механических противопоставлений, парных лозунгов и одинакового ритма абзацев. Все слова внутри одного заголовка должны быть одного цвета.
- Демонстрационные сценарии и метрики явно обозначаются как примеры; вымышленные результаты не выдаются за реальные кейсы.
- Крупные наборы контента хранятся отдельно от компонентов. Код — TypeScript strict, семантический HTML и доступный адаптивный интерфейс.
- Светлая, спокойная визуальная система: потоки данных, сигналы и интерфейсные примеры вместо стоковых людей и AI-клише. Анимация умеренная и учитывает `prefers-reduced-motion`.
- Каждая новая фича получает автотесты, запускаемые при каждой сборке. При провале исправляется причина и сборка повторяется.
- Перед задачей читать все файлы `docs/ai/`. Обновлять `CURRENT_STATE.md` при изменении кода, фиксировать архитектурные решения в `DECISIONS.md`, а завершение задачи — в `CHANGELOG_AI.md`. Память содержит только итоговые факты, без логов и временных гипотез.
- Команды: `npm install`, `npm run dev`, `npm run format`, `npm run build`, `npm run preview`. Для canonical/OG URL на deployment задать `VITE_SITE_URL` по образцу `.env.example`.
