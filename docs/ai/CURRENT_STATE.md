# Текущее состояние

На 2026-10-04 сайт содержит адаптивную главную `/`, страницы обзора `/solutions` и `/industries`, четыре страницы решений, четыре отраслевые страницы, `/1c`, `/cases`, `/projects`, `/approach`, `/about` и `/contact`. Header, Footer и главная связывают разделы между собой. Интерактивный UI-макет `Altacod Radar` доступен на главной и собственной странице. Сценарии и показатели явно обозначены как демонстрационные; подтверждённых клиентских кейсов пока нет.

Витрина `/projects` показывает шесть проектов, выбранных владельцем: WibeStyle, AltaKid, Publisher, Любимая Дача, Военсовет и AltaTrade. Написание WibeStyle взято из существующего каталога и домена `wibestyle.ru`. Ссылки ведут на будущие адреса каталога `products.altacod.com/apps/<slug>`. Текущие иллюстрации карточек — абстрактные схемы интерфейса, не скриншоты продуктов; перед выпуском их нужно заменить подтверждёнными изображениями. Publisher обозначен временно остановленным, AltaTrade — проектом в работе.

На всех внутренних страницах есть хлебные крошки с переходом на главную и, для вложенных страниц, на обзорный раздел. Текущая страница выделена без ссылки. На главной крошки скрыты.

Правила живого русского текста закреплены в `CONVENTIONS.md` и применены к внутренним страницам: без механических противопоставлений, парных лозунгов и одинакового ритма абзацев. В интерфейсе используется «ИИ»; слова внутри каждого заголовка одного цвета. Блоки о Сергее описывают его роль спокойно и конкретно.

Контакт: `info@altacod.com`. Страница `/contact` формирует черновик `mailto` из описания задачи; посетитель сам подтверждает отправку в почтовой программе и вручную прикладывает выбранный файл. Загрузки файла и backend нет. Telegram и MAX пока не подключены, так как ссылки не предоставлены.

Есть favicon, социальная карточка, динамические метаданные SEO для каждого маршрута и настройка `VITE_SITE_URL`. После сборки создаются отдельные HTML-файлы с метаданными 17 маршрутов, sitemap.xml и robots.txt. Новый счётчик Яндекс Метрики `113399075` включается только на публичном корпоративном домене; просмотры SPA-маршрутов учитываются отдельно, без дубля первого просмотра. Производственная сборка проходит с TypeScript strict и 39 тестами в 14 файлах, запускаемыми каждым `npm run build`. Внутренние страницы и крошки ранее проверены в браузере на десктопе и мобильном экране; новую витрину предстоит проверить визуально. Ранее для главной получены мобильные показатели Lighthouse: Performance 99, Accessibility 100, Best Practices 100, SEO 100; после добавления страниц замер не повторялся.

Целевой публичный домен — `altacod.com`; существующий каталог предстоит перенести на `products.altacod.com`. Coolify находится на домашнем сервере без белого IP, куда SSH-доступ уже имеется. Отдельный reverse proxy с Caddy расположен на Timeweb. SSH-вход на Timeweb (`root@89.223.66.64`) через локальный `ssh-agent` проверен; конфигурация Caddy и связка nginx → Caddy изучены только чтением. Действующий `altacod.com` направляется на каталог `altacod-apps.sslip.io`; маршруты ещё не менялись. Backend формы и развёртывание пока отсутствуют. Dockerfile создан, но контейнер локально не проверен: доступ к Docker daemon сейчас не подтверждён. Git-репозиторий существует, удалённый origin — `https://github.com/sergiologino/Altacod_radar.git`. Telegram и MAX добавятся после предоставления ссылок.
