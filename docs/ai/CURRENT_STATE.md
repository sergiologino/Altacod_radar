# Текущее состояние

На 2026-10-04 сайт содержит адаптивную главную `/`, страницы обзора `/solutions` и `/industries`, четыре страницы решений, четыре отраслевые страницы, `/1c`, `/cases`, `/projects`, `/approach`, `/about` и `/contact`. Header, Footer и главная связывают разделы между собой. Интерактивный UI-макет `Altacod Radar` доступен на главной и собственной странице. Сценарии и показатели явно обозначены как демонстрационные; подтверждённых клиентских кейсов пока нет.

Витрина `/projects` показывает шесть проектов, выбранных владельцем: WibeStyle, AltaKid, Publisher, Любимая Дача, Военсовет и AltaTrade. Написание WibeStyle взято из существующего каталога и домена `wibestyle.ru`. Ссылки ведут на действующие адреса каталога `products.altacod.com/apps/<slug>`; все шесть проверены публичным HTTPS-запросом и отвечают 200. Текущие иллюстрации карточек — абстрактные схемы интерфейса, не скриншоты продуктов; их можно заменить подтверждёнными изображениями. Publisher обозначен временно остановленным, AltaTrade — проектом в работе.

На всех внутренних страницах есть хлебные крошки с переходом на главную и, для вложенных страниц, на обзорный раздел. Текущая страница выделена без ссылки. На главной крошки скрыты.

Правила живого русского текста закреплены в `CONVENTIONS.md` и применены к внутренним страницам: без механических противопоставлений, парных лозунгов и одинакового ритма абзацев. В интерфейсе используется «ИИ»; слова внутри каждого заголовка одного цвета. Блоки о Сергее описывают его роль спокойно и конкретно.

Контакт: `info@altacod.com`. В опубликованной версии страница `/contact` ещё формирует черновик `mailto`. В рабочем коде подготовлены форма с обязательным проверяемым email, прямой отправкой и вложением до 10 МБ и отдельный API через Mailu (`noreply@altacod.com` → `info@altacod.com`, `Reply-To` посетителя). Отдельное приложение `altacod-radar-api` создано в проекте Radar в Coolify, несекретные SMTP-переменные заданы. API и новая форма ещё не опубликованы: для выпуска нужен пароль ящика в Coolify, успешное развёртывание API и адресный маршрут Caddy. Предложенное изменение Caddy прошло `caddy validate`, но не применено. Telegram и MAX пока не подключены, так как ссылки не предоставлены.

Есть favicon, социальная карточка, динамические метаданные SEO для каждого маршрута и настройка `VITE_SITE_URL`. После сборки создаются отдельные HTML-файлы с метаданными 17 маршрутов, sitemap.xml и robots.txt. Новый счётчик Яндекс Метрики `113399075` включается только на публичном корпоративном домене; просмотры SPA-маршрутов учитываются отдельно, без дубля первого просмотра. Производственная сборка проходит с TypeScript strict и 44 тестами (39 frontend, 5 API), запускаемыми каждым `npm run build`. Внутренние страницы и крошки ранее проверены в браузере на десктопе и мобильном экране; новую витрину предстоит проверить визуально. Ранее для главной получены мобильные показатели Lighthouse: Performance 99, Accessibility 100, Best Practices 100, SEO 100; после добавления страниц замер не повторялся.

Корпоративный сайт опубликован на `https://altacod.com`, существующий каталог — на `https://products.altacod.com`. Coolify находится на домашнем сервере без белого IP, отдельный reverse proxy с Caddy — на Timeweb. Новый проект `altacod-radar` создан в Coolify из публичного Git-репозитория `https://github.com/sergiologino/Altacod_radar.git` (ветка `master`, Dockerfile, порт 80); развёрнут коммит `2ac1249`. Каталог остаётся в своём приложении Coolify, для него добавлены hostname `products.altacod.com` и переменные `NEXT_PUBLIC_SITE_URL=https://products.altacod.com`, `NEXT_PUBLIC_YANDEX_METRIKA_ID=109312391`; пересборка прошла успешно. A-запись `products.altacod.com → 89.223.66.64` подтверждена авторитативным DNS и публичным резолвером.

В Caddy на Timeweb добавлены блоки каталога, переключён upstream Host двух блоков `altacod.com` на новое приложение и настроены адресные HTTP-переходы на HTTPS для `altacod.com`, `www.altacod.com` и `products.altacod.com` кодом 308. Конфигурация прошла `caddy validate`, служба работает после reload; резервные копии сохранены как `/etc/caddy/Caddyfile.backup-altacod-20261004`, `/etc/caddy/Caddyfile.backup-altacod-cutover-20261004` и `/etc/caddy/Caddyfile.backup-altacod-https-20261004`. Публичные HTTPS-запросы проверили главную нового сайта (200, счётчик Метрики `113399075`), шесть страниц каталога (200), перенаправление `www.altacod.com` на apex и старых `/apps/*` на `products.altacod.com` кодом 308 с сохранением пути и параметров. Проверенные маршруты `finds.altacod.com` и `learn.altakid.ru` отвечают 200. Backend формы отсутствует. Telegram и MAX добавятся после предоставления ссылок.
