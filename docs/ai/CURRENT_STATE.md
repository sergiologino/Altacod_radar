# Текущее состояние

На 2026-10-04 сайт содержит адаптивную главную `/`, страницы обзора `/solutions` и `/industries`, четыре страницы решений, четыре отраслевые страницы, `/1c`, `/cases`, `/approach`, `/about` и `/contact`. Header, Footer и главная связывают разделы между собой. Интерактивный UI-макет `Altacod Radar` доступен на главной и собственной странице. Сценарии и показатели явно обозначены как демонстрационные; подтверждённых клиентских кейсов пока нет.

На всех внутренних страницах есть хлебные крошки с переходом на главную и, для вложенных страниц, на обзорный раздел. Текущая страница выделена без ссылки. На главной крошки скрыты.

Правила живого русского текста закреплены в `CONVENTIONS.md` и применены к внутренним страницам: без механических противопоставлений, парных лозунгов и одинакового ритма абзацев. В интерфейсе используется «ИИ»; слова внутри каждого заголовка одного цвета. Блоки о Сергее описывают его роль спокойно и конкретно.

Контакт: `info@altacod.com`. Страница `/contact` формирует черновик `mailto` из описания задачи; посетитель сам подтверждает отправку в почтовой программе и вручную прикладывает выбранный файл. Загрузки файла и backend нет. Telegram и MAX пока не подключены, так как ссылки не предоставлены.

Есть favicon, социальная карточка, `robots.txt`, динамические метаданные SEO для каждого маршрута и настройка `VITE_SITE_URL`. Производственная сборка проходит с TypeScript strict и 29 тестами в 9 файлах, запускаемыми каждым `npm run build`. Внутренние страницы и крошки проверены в браузере на десктопе и мобильном экране; горизонтального переполнения на проверенных маршрутах и ошибок консоли нет. Ранее для главной получены мобильные показатели Lighthouse: Performance 99, Accessibility 100, Best Practices 100, SEO 100; после добавления страниц замер не повторялся.

Для выпуска нужны публичный домен и ссылки Telegram/MAX, если эти каналы будут добавлены. Метаданные внутренних страниц обновляются в браузере; серверная выдача отдельного HTML для соцсетей и поисковых роботов пока не реализована. Backend формы и развёртывание отсутствуют. Dockerfile создан, но контейнер не собран локально из-за остановленного Docker daemon. Git-репозиторий в каталоге не инициализирован.
