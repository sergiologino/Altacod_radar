# Архитектура

Проект — один frontend-сервис: React 19, TypeScript strict, Vite 8, Tailwind CSS 4, React Router 7. Маршруты включают главную, обзоры решений и отраслей, девять предметных страниц, примеры задач, витрину проектов, подход, автора и контакт. Страницы решений и отраслей используют общую композицию с отдельным контентом для каждой задачи.

Код: `src/App.tsx` содержит маршруты и обновляет метаданные страницы; `src/pages` — главную, предметные страницы, витрину проектов и контактную форму; `src/components` — Header, Footer, хлебные крошки, схемы и интерактивный Radar; `src/data` — контент страниц и метаданные маршрутов; `src/lib` — расчёт демонстрационного заказа, SEO URL, дерево хлебных крошек и формирование почтового черновика; `src/styles` — базовая и внутренняя визуальная система. Radar загружается отдельным чанком. Иллюстрации витрины сейчас построены CSS и не являются скриншотами продуктов.

Хлебные крошки строятся из текущего маршрута и карты предметных страниц: главная → обзор решений или отраслей → страница темы. На самостоятельных страницах путь состоит из главной и текущей страницы. Последний элемент помечен `aria-current="page"`, предыдущие доступны как ссылки; на главной крошки не показываются.

Демо Radar хранит состояние только в браузере. Скидка пересчитывает выручку, прибыль и маржу из явно заданных демонстрационных затрат. Остальные два сигнала — статичные демонстрационные сценарии. Никаких данных клиента, backend или отправки событий пока нет.

Публичный адрес для canonical и OpenGraph задаётся `VITE_SITE_URL`; если переменная не задана, используется origin текущего запроса. Метаданные внутреннего маршрута обновляются при навигации на клиенте. `scripts/generate-static-pages.mjs` создаёт HTML-файл с индивидуальными SEO-метаданными для каждого маршрута из `src/data/routeMeta.json`, sitemap и robots.txt после Vite build. Контактная форма формирует `mailto:info@altacod.com` и не отправляет данные с сайта; выбранный файл нужно приложить в почтовой программе. Telegram и MAX добавляются после получения ссылок. При появлении backend способ отправки следует отделить от UI.

`npm run build` последовательно выполняет проверку типов, все автотесты, production-сборку и генерацию HTML по маршрутам. Dockerfile собирает приложение в Node и отдаёт через nginx: `try_files $uri/index.html $uri /index.html` выдаёт HTML конкретного маршрута, а для неизвестного пути оставляет SPA fallback. Сборочный аргумент `VITE_SITE_URL` имеет значение `https://altacod.com`. Контейнерный запуск локально не проверен.

Планируемая инфраструктура: Coolify и приложения, включая backend AltaKid, работают на домашнем сервере без белого IP. Публичный reverse proxy с Caddy находится на отдельном сервере Timeweb и направляет запросы к домашнему серверу. SSH-доступ к домашнему серверу уже существует; для сервера Timeweb создаётся отдельный ключ. Это два разных узла и два независимых доступа.
